# สมุดจ่ายรายวัน (PWA)

แอปบันทึกค่าใช้จ่ายส่วนตัว ใช้คนเดียว ข้อมูลเก็บในเครื่องเท่านั้น

## ไฟล์
- `index.html` ตัวแอปทั้งหมด
- `manifest.json` ข้อมูลแอปสำหรับติดตั้ง (theme `#0a2d6e`)
- `sw.js` ทำให้เปิดได้แบบออฟไลน์ และรับสลิปที่แชร์มาจากแอปธนาคาร (Android)
- `` ไอคอนแอป 192, 512, maskable, apple-touch, favicon

## Deploy ขึ้น GitHub Pages
1. สร้าง repo ใหม่ เช่น `money-diary` ในบัญชี `aiewjung11-commits`
2. อัปโหลดไฟล์ทั้งหมด (ทั้ง 9 ไฟล์) ไว้ที่ root ของ repo
3. Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save
4. เปิด `https://aiewjung11-commits.github.io/money-diary/`
5. ติดตั้งลงหน้าจอ
   - iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
   - Android: Chrome → ⋮ → ติดตั้งแอป

## อัปเดตเวอร์ชัน
แก้ `index.html` แล้วเปลี่ยน `VERSION` ใน `sw.js` (เช่น `money-v2`) เพื่อให้เครื่องโหลดไฟล์ใหม่

## หมายเหตุ
- อ่านสลิปด้วย Tesseract.js (OCR ภาษาไทย + อังกฤษ) รันในเครื่อง ครั้งแรกต้องต่อเน็ตเพื่อโหลดตัวอ่าน (~10 MB) หลังจากนั้นใช้ออฟไลน์ได้
- รูปสลิปเก็บใน IndexedDB ของเบราว์เซอร์ ถ้าล้างข้อมูลเบราว์เซอร์หรือลบแอป ข้อมูลจะหาย ควรสำรองจากเมนู → สำรองทั้งหมดพร้อมรูปสลิป เป็นประจำ
- ย้ายข้อมูลจากเวอร์ชันใน Claude: ส่งออก CSV จากเวอร์ชันเดิม แล้วใช้เมนู → นำเข้า CSV
